My /api page is a retro Quiz Arcade Machine. Questions come live from the Open Trivia Database and appear on the glowing screen of an arcade cabinet. You pick a category and difficulty, answer before the timer runs out, and you have three lives. It is unique because instead of showing trivia data as a list, it turns it into a playable arcade game with a score, lives and sound-style feedback.

API: Open Trivia DB (opentdb.com)
CACHE: 5-Min In-Memory Server Cache
ENGINE: Python Flask + Web Audio API
