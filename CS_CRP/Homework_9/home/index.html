PROJECT

Microsecond Reflex Duel and Simon Game

Technology used: GPIO with hardware interrupts (attachInterrupt, INPUT_PULLUP) on an ESP32, simulated in Wokwi.

Coding agent: Claude

Parts list

  • 1 × ESP32 DevKit
  • 4 × pushbuttons (B1 to B4)
  • 6 × LEDs: red, green, blue, yellow, white, orange
  • 6 × 220 Ω resistors (one per LED)

WHAT IT DOES

Explanation

This project is an ESP32 arcade built entirely on GPIO and hardware interrupts. A start menu lets the player choose between a two-player Reflex Duel and a one-player Simon memory game. Every button press triggers an interrupt that records a microsecond timestamp, so reaction times are measured without polling the pins. The Serial Monitor prints every result, together with an interrupt health report, as proof that the system works.

FULL EXTENT

How I pushed the technology

All four buttons use their own interrupt service routine that feeds a shared ring-buffer queue, with debouncing and the micros() timestamp done inside the ISR at the moment of the press. Both games run on the same interrupt system and handle edge cases such as false starts, near ties, timeouts, wrong answers and keyboard key-repeat. Live counters for raw edges, accepted presses, rejected bounces and dropped events show that no tap is missed.

HOW IT WORKS

Circuit diagram

Interrupt chain

  1. Button press: with INPUT_PULLUP the pin is HIGH, and pressing pulls it LOW (a FALLING edge).
  2. Hardware interrupt: the FALLING edge fires attachInterrupt instantly, with no polling.
  3. ISR (IRAM_ATTR): reads micros(), ignores edges within 20 ms (debounce) and stores the press.
  4. Ring buffer: a 16-slot queue of {button, timestamp} holds presses until loop() is ready.
  5. Game logic in loop(): decides what each press means: a win, a false start or a wrong colour.
  6. Serial Monitor: prints the result and the interrupt health counters.

Reflex Duel (2 players)

Wait for the white LED, then press your button first. Pressing early is a false start (orange LED) and you lose the round. The Serial Monitor prints each reaction time in microseconds, flags a near tie when the presses are less than 1 ms apart, and keeps wins, best and average times. If nobody presses within 3 seconds the round times out. After each round, press B4 within 2 seconds to return to the menu.

Simon (1 player)

Watch the colour pattern, then repeat it with B1 to B4. The pattern grows by one step each round and gets slightly faster. A wrong button or 8 seconds without an answer ends the game (orange LED). Complete 12 steps to win.
